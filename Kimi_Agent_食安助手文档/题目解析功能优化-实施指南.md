## 📋 功能概述

为食安答题助手增加题目解析功能：
- 数据库新增 `analysis` 字段存储题目解析
- 前端界面标题从"题目生成"改为"生成题目解析"
- 搜索结果中增加题目解析内容展示

---

## 🗄️ 数据库操作

### 第一步：添加字段

在 Supabase Dashboard 的 SQL Editor 中执行：

```sql
-- 文件位置：Kimi_Agent_食安助手文档/04_添加题目解析字段.sql

-- 添加analysis字段（如果不存在）
DO $$ 
BEGIN
    IF NOT EXISTS (
        SELECT 1 
        FROM information_schema.columns 
        WHERE table_schema = 'public' 
        AND table_name = 'questions' 
        AND column_name = 'analysis'
    ) THEN
        ALTER TABLE public.questions ADD COLUMN analysis TEXT;
        COMMENT ON COLUMN public.questions.analysis IS '题目解析';
        RAISE NOTICE '成功添加analysis字段';
    ELSE
        RAISE NOTICE 'analysis字段已存在，跳过添加';
    END IF;
END $$;
```

**执行方式：**
1. 打开 Supabase Dashboard
2. 进入 SQL Editor
3. 复制上面的 SQL 并执行

---

### 第二步：导入解析数据

#### 方法A：使用 Python 脚本自动生成 SQL（推荐）

```bash
# 在项目根目录执行
cd E:\2026\AI开发\食安答题助手
python 导入题目解析_脚本.py
```

脚本会自动：
1. 读取 `questions_rows_with_analysis.csv` 文件
2. 生成 SQL UPDATE 语句
3. 输出到 `Kimi_Agent_食安助手文档/05_导入题目解析_完整数据.sql`

然后：
1. 打开生成的 SQL 文件
2. 复制全部内容
3. 在 Supabase SQL Editor 中执行

#### 方法B：直接导入（小数据量）

如果只有少量数据，可以手动在 SQL Editor 执行：

```sql
UPDATE public.questions 
SET analysis = '解析内容' 
WHERE id = '题目ID';
```

## 🔧 故障排查

### 问题1：字段添加失败

**错误：** `column "analysis" already exists`

**解决：** 字段已存在，跳过此步骤，直接导入数据

### 问题2：数据导入失败

**错误：** `invalid input syntax for type uuid`

**解决：** 检查CSV文件中的ID格式是否正确

### 问题3：前端不显示解析

**原因：** 
- 数据库中analysis字段为空
- 前端缓存未更新

**解决：**
```bash
# 清除缓存并重新构建
cd app
rm -rf node_modules/.vite
npm run build
```
