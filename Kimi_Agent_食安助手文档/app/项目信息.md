📋 项目概览
项目名称: 食安AI答题助手
这是一个面向福建省食安人员的在线答题辅助工具,通过AI技术帮助用户快速匹配食安考试题目并提供答案解析。
 
🏗️ 技术架构
前端: React + TypeScript + Vite
UI框架: Tailwind CSS + shadcn/ui组件库
后端: Supabase (PostgreSQL + Auth)
部署: 静态网站托管
 
👥 用户角色
1. 普通用户 - 福建省各企业食安人员
注册登录(手机号+地区)
AI答题(搜索题目获取答案)
缴费充值(上传缴费凭证)
查看使用记录
2. 系统管理员 - admin账号
题库管理(查询、浏览)
用户管理(查询、编辑、禁用)
缴费管理(审核缴费记录)
数据统计(用户/缴费/使用统计)
系统设置(收款码、提示文案配置)
 
🗄️ 数据库设计
核心数据表包括:
questions - 题库表(题目、选项、答案)
regular_users - 普通用户表(手机号、地区、可用题数)
payment_records - 缴费记录表(凭证图片、审核状态)
usage_records - 使用记录表(搜索内容、使用次数)
system_config - 系统配置表(收款码、提示信息)
admins - 管理员表
 
💡 核心功能
用户端功能:
AI答题页
输入题目关键词(最少6个字)
模糊搜索匹配题库
显示题目、选项、答案
每次搜索扣减1次可用题数
缴费充值页
显示收款码和缴费说明
上传缴费凭证截图(Base64存储)
查看历史缴费记录和审核状态
使用记录页
分页显示历史使用记录
显示搜索内容、匹配题数、使用时间
管理端功能:
题库管理 - 按业态/题型/内容查询题目
用户管理 - 查询、编辑用户信息,调整可用题数
缴费管理 - 审核用户上传的缴费凭证
数据统计 - 查看各类统计数据
系统设置 - 配置收款码、答题提示、单题价格等
 
🔐 安全机制
RLS策略: 行级安全控制,用户只能访问自己的数据
手机号校验: 正则验证11位手机号
图片压缩: 上传时自动压缩图片减少存储空间
JWT认证: 基于Supabase Auth的Token认证
 
📱 响应式设计
PC端: 左侧导航菜单 + 右侧内容区
移动端: 底部Tab导航栏,全屏布局
支持微信网页适配
 
🎯 业务逻辑亮点
试用机制: 新用户注册赠送2题试用
计费模式: 1元可使用1次答题功能（支持系统配置）
缴费审核: 用户上传凭证 → 管理员审核 → 自动增加可用题数(金额×2)
智能搜索: 使用pg_trgm扩展实现模糊匹配,支持相似度排序
