想要在手机上真实体验，将项目部署到 **GitHub Pages** 是最快且免费的方案。由于你的项目是基于 Vite 开发的，部署过程非常标准化。

以下是详细的步骤：

### **第一步：准备 GitHub 仓库**

1.  登录你的 [GitHub](https://github.com/) 账号。
2.  创建一个新仓库（New repository），起个名字（例如：`saks-ai`）。
3.  保持仓库为 **Public**（公开），然后点击 **Create repository**。

---

### **第二步：修改项目配置文件**

由于 GitHub Pages 的访问地址通常是 `https://<你的用户名>.github.io/<仓库名>/`，我们需要告诉 Vite 基础路径。

1.  在 Trae 中打开 [app/vite.config.ts](file:///e:/2026/AI开发/食安答题助手/Kimi_Agent_食安助手文档/app/vite.config.ts)。
2.  在 `defineConfig` 中添加 `base` 配置：
    ```typescript
    export default defineConfig({
      plugins: [react()],
      base: '/saks-ai/', // 这里替换成你刚才创建的 GitHub 仓库名
      resolve: {
        alias: {
          "@": path.resolve(__dirname, "./src"),
        },
      },
    })
    ```

---

### **第三步：推送代码到 GitHub**

在 Trae 的终端中执行以下命令（请确保你已经安装了 [Git](https://git-scm.com/)）：

1.  **进入 app 目录**：
    ```powershell
    cd app
    ```
2.  **初始化 Git 并提交**：
    ```powershell
    git init
    git add .
    git commit -m "Initial commit"
    ```
3.  **关联远程仓库并推送**：
    ```powershell
    git remote add origin https://github.com/<你的用户名>/saks-ai.git
    git branch -M main
    git push -u origin main
    ```

---

### **第四步：使用 GitHub Actions 自动部署 (最推荐)**

这是目前最现代的部署方式，以后你每次修改代码并 `git push`，网页都会自动更新。

1.  在 `app` 目录下创建目录结构：`.github/workflows`。
2.  在该目录下创建一个文件 `deploy.yml`，内容如下：
    ```yaml
    name: Deploy to GitHub Pages

    on:
      push:
        branches: [ main ]

    permissions:
      contents: read
      pages: write
      id-token: write

    jobs:
      build:
        runs-on: ubuntu-latest
        steps:
          - uses: actions/checkout@v4
          - uses: actions/setup-node@v4
            with:
              node-version: 20
              cache: 'npm'
              cache-dependency-path: app/package-lock.json
          - name: Install and Build
            run: |
              cd app
              npm install
              npm run build
          - name: Upload artifact
            uses: actions/upload-pages-artifact@v3
            with:
              path: app/dist

      deploy:
        needs: build
        runs-on: ubuntu-latest
        environment:
          name: github-pages
          url: ${{ steps.deployment.outputs.page_url }}
        steps:
          - id: deployment
            uses: actions/deploy-pages@v4
    ```
3.  将此文件提交并推送：
    ```powershell
    git add .
    git commit -m "Add deploy workflow"
    git push
    ```

---

### **第五步：开启 GitHub Pages 设置**

1.  回到 GitHub 网页，进入仓库的 **Settings** -> **Pages**。
2.  在 **Build and deployment** -> **Source** 下，选择 **GitHub Actions**。
3.  点击顶部的 **Actions** 标签页，你会看到一个正在运行的任务。等它变成绿色勾选，部署就完成了！

---

### **如何用手机访问？**

部署完成后，GitHub 会给你一个链接，格式如下：
`https://<你的用户名>.github.io/saks-ai/`

**微信体验建议：**
*   将该链接通过电脑版微信发送给你的手机。
*   在手机微信中点击打开。
*   你可以点击微信右上角的 **“...”**，选择 **“添加到浮窗”** 或 **“添加到桌面”**，方便随时测试。

**注意：** 因为你使用了 Supabase，请确保在 Supabase 后台的 **Authentication -> Allow List** 中添加了你的 GitHub 域名，否则可能会拦截跨域请求（不过由于你使用的是 `anon` key，通常不会有跨域拦截）。
